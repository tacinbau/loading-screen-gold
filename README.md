One sharp, funny loading-screen tip for stressed developers and AI coding
agents, in 200 characters or fewer — written to `/output/entry.txt` by
`main.ts`.

## The tip

> Tip: the agent rewrote your code in 9 seconds. You'll spend 40 minutes proving it wrong. That's not a bug — that's the job now.

(127 characters — inside the 200-character gate.)

## Run

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` and refuses to write
anything if the line ever grows past 200 characters.
